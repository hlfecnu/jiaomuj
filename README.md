# 酵母合成生物学文献库

一个用 Europe PMC 公开接口自动搜集 2020 年以来全部收录期刊中酵母基因改造与合成生物学文献的网站，不再限制为固定 CNS 期刊白名单。

公网地址：<https://hlfecnu.github.io/jiaomuj/>

## 使用方式

```powershell
npm start
```

然后打开终端里显示的网址。服务默认尝试 `http://127.0.0.1:5174`，如果端口被占用会自动递增到 `5175`、`5176` 等。

也可以双击 `start.bat`。另一台设备需要先安装 Node.js 18 或更新版本。

## 自动更新

GitHub Actions 每天北京时间 09:00 自动更新公网数据。本地服务启动后也会把下一次自动更新排到明天 09:00，之后每天 09:00 更新一次。更新时会：

- 调用 Europe PMC 搜集文献
- 生成中文标题和中文摘要
- 保存到 `data/literature.json`
- 缓存翻译到 `data/translation-cache.json`
- 在页面里提供 DOI、PubMed 和原文跳转链接

页面支持：

- 全部 Europe PMC 收录期刊的主题检索
- 自动去重、按日期排序
- 中文标题、摘要、作者、期刊、DOI 过滤
- 文献综合评分、相关度评分及引用次数
- 按同主题文献动态计算的期刊评分与站内 Q1-Q4 分区
- 酿酒酵母、布拉氏酵母、毕赤酵母及基因组编辑、CRISPR、代谢工程等中文关键词标签
- CSV 和 JSON 导出
- 服务端本地缓存上次结果

公网版点击“重新加载”会读取 GitHub 上已更新的数据；自定义检索参数和“立即更新”功能保留在本地 Node 服务中。

默认数据源是 Europe PMC REST API，不需要 API key。中文翻译使用公开翻译端点，首次全量翻译会比普通检索慢。

## 评分与分区口径

- 文献评分（0-100）：综合主题相关度、年均引用、数据完整性和发表时间。
- 相关度（0-100）：根据标题和摘要中酵母物种、基因改造与合成生物学技术词的命中位置及丰富度计算。
- 站内 Q1-Q4：对当前同主题文献集合中的期刊评分进行四分位排序，不等同于 JCR 分区或中科院分区。
- JCR 影响因子和中科院分区属于授权数据；仓库支持后续接入正版数据，但不会用推算值冒充官方指标。
